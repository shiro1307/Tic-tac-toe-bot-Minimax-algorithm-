# Mini Tic Tac Toe - Player vs Bot

A simple browser based Tic Tac Toe game built using HTML, CSS, and vanilla JavaScript. The player competes against a bot that uses the Minimax algorithm.
Play here: https://shiro1307.github.io/Tic-tac-toe-bot-Minimax-algorithm-/

## Features

- Player vs Bot gameplay  
- Bot powered by Minimax  
- Win detection for rows, columns, and diagonals  
- Visual win line  
- Basic sound effects  
- Replay button  

## How It Works

The bot uses a recursive Minimax algorithm to evaluate possible moves:

- +1 for bot win  
- -1 for player win  
- 0 for draw  

The bot chooses the move with the best possible outcome.
